# Смоук-сценарии (Playwright)

Здесь лежат «дымовые» проверки: приложение открывается, вход работает, список
чатов и переписка открываются, меню «⋯» на месте, настройки приватности
открываются. Они ходят по **настоящему** развёрнутому приложению (по умолчанию —
прод `https://pismo.space`), поэтому в общий прогон тестов и в CI **не входят**:
`vitest.config.ts` папку `e2e/**` исключает, а пакет `@playwright/test` в
зависимости проекта не добавлен (иначе он тянулся бы в сборку образа).

Запускаются руками, когда нужно убедиться, что «живой» сайт не отвалился:
после выката, после ротации сертификатов, после правок в nginx.

## Как запустить

```bash
cd frontend
pnpm add -D @playwright/test          # разово, локально; в репозиторий не коммитим
pnpm exec playwright install chromium # разово, локально
E2E_PHONE='+7…' E2E_PASSWORD='…' \
  pnpm exec playwright test -c e2e/playwright.config.ts
```

Переменные окружения (секретов в репозитории нет и быть не должно):

| Переменная     | Зачем                                                        |
| -------------- | ------------------------------------------------------------ |
| `E2E_BASE_URL` | Адрес приложения. По умолчанию `https://pismo.space`.        |
| `E2E_PHONE`    | Номер тестового аккаунта (в формате `+7…`).                  |
| `E2E_PASSWORD` | Пароль тестового аккаунта.                                   |

Без `E2E_PHONE`/`E2E_PASSWORD` сценарии, которым нужен вход, **пропускаются**
(`test.skip`), а проверки экрана входа всё равно прогоняются.

Для локального стенда: `E2E_BASE_URL=https://localhost:8443` (или на адрес
dev-сервера) — самоподписанный сертификат не мешает, в настройках стоит
`ignoreHTTPSErrors`.

## Что проверяют сценарии

| Файл                       | Что проверяет                                                     |
| -------------------------- | ----------------------------------------------------------------- |
| `smoke-login.spec.ts`      | Неавторизованного уводит на вход, форма на месте, ошибка видна.    |
| `smoke-chats.spec.ts`      | После входа виден список чатов, открывается переписка и шапка.     |
| `smoke-clear-history.spec.ts` | Меню «⋯» → «Очистить историю» → вопрос и кнопки; **отмена**.     |
| `smoke-presence.spec.ts`   | Настройки → «Приватность»: переключатель присутствия на месте.      |

Важно: сценарии **ничего не меняют**. «Очистить историю» только открывается и
закрывается кнопкой «Отмена», а переключатель присутствия возвращается в исходное
положение — тестовый аккаунт остаётся таким, каким был.

## Если сценарий упал

Playwright сохраняет след в `frontend/e2e/test-results`: снимок экрана, трейс и
видео (только для упавших). Трейс открывается так:

```bash
pnpm exec playwright show-trace e2e/test-results/<папка>/trace.zip
```

Папку `test-results` в репозиторий не коммитим (она в `.gitignore`).
