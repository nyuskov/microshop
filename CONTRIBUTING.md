# Как участвовать

Спасибо за интерес к проекту. Ниже — минимальный путь, чтобы правка прошла
проверки и её было легко ревьюить (код и документация — по-русски).

## Что нужно

- Python 3.13 + [Poetry](https://python-poetry.org/);
- Node.js 22+ и pnpm (версия зафиксирована в `frontend/pnpm-lock.yaml`);
- Docker и Docker Compose (dev-стек, тестовая БД, сборка Android);
- для e2e — Chromium от Playwright (ставится локально, в зависимости проекта
  не входит).

## Быстрый старт

```bash
cp .env.example .env        # задайте свои значения, .env в git не попадает
docker compose up --build   # backend :8000, frontend :5173, nginx :8080
```

Полное описание запуска, переменных и структуры — в [README.md](README.md) и
`docs/`.

## Перед pull request

```bash
make check          # линтеры, типы, тесты с покрытием, стражи стилей и бюджет
make test-backend   # pytest на одноразовой БД в контейнере
```

`make check` — то же, что гоняет CI. Отдельно, если трогали shell-скрипты:

```bash
shellcheck -x --severity=warning $(git ls-files '*.sh')
node scripts/check-docs-links.mjs
```

e2e-сценарии (Playwright) запускаются руками по живому стенду — см.
[`frontend/e2e/README.md`](frontend/e2e/README.md).

## Правила правок

- Одна задача — один PR; не смешивайте рефакторинг и поведение.
- Сообщения коммитов — по-русски, формат `тип(область): что сделано`
  (`fix(звонки): …`, `docs(README): …`).
- Меняете функционал — обновите `docs/changelog.md` и, если он виден
  пользователю, опубликуйте пост в канал «Новости приложения» (это делает
  владелец).
- Меняете модель/схему — добавьте миграцию Alembic (`make test-backend`
  проверяет дрейф).
- Меняете API — обновите снимок: `make api-schema`, затем
  `cd frontend && pnpm typegen`.
- Тексты интерфейса — через `frontend/src/i18n/` (ключ = русский текст,
  английский — в `en.ts`); серверные тексты — `backend/core/i18n*.py`.
- Секреты и персональные данные не коммитим: `.env`, keystore, реальные номера
  и адреса заменяем заглушками (`example.com`, `+7999…`).
