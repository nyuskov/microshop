# Кодекс поведения

Проект открыт для всех. Мы ожидаем уважительного и конструктивного общения —
в issues, pull request'ах, обсуждениях и любых других каналах проекта.

## Ожидается

- Критикуйте код и решения, а не людей; объясняйте, что и почему улучшить.
- Учитывайте контекст: проект развивает один человек, часть решений осознанная.
- Уважайте приватность: не публикуйте чужие персональные данные, переписку,
  ключи, дампы и скриншоты с реальными пользователями.
- Помогайте новичкам: вопрос «как запустить» — нормальный.

## Недопустимо

- Оскорбления, травля, угрозы, дискриминация по любому признаку.
- Публикация чужих персональных данных и секретов.
- Спам, реклама и PR, не относящиеся к проекту.
- Намеренное нарушение работы сервиса или попытки атаковать чужой стенд.

## Модерация

Нарушения рассматривает владелец репозитория: предупреждение, затем блокировка
участия. Сообщить о нарушении можно приватно через GitHub (или через
Security-канал, см. [SECURITY.md](SECURITY.md)), если речь о безопасности.

Этот документ опирается на ценности
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
