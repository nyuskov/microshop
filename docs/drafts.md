# Черновики сообщений на сервере

Черновик — недописанный текст в поле ввода. Раньше он жил только в
`localStorage` браузера: терялся при переустановке приложения и не был виден с
другого устройства. Теперь он хранится на сервере.

## Что где лежит

| | Где | Что хранится |
|---|---|---|
| Сервер | таблица `message_drafts`, PK `(user_id, chat_id)` | текст в том же виде, что уходит в сообщение |
| Браузер | `localStorage`, ключ `pismo_drafts` | открытый текст (только своё устройство) |

Обе копии нужны: локальная даёт мгновенный показ при запуске (до ответа API) и
работает без сети, серверная переживает переустановку и видна с другого
устройства.

## Сквозное шифрование

Текст черновика не разбирается на сервере: в чате со сквозным шифрованием
клиент отправляет в `/drafts/{chat_id}/` **шифротекст** (тот же формат, что у
сообщений). Сервер хранит строку и отдаёт её владельцу — прочитать черновик он
не может, как и сообщение. При загрузке клиент расшифровывает черновик ключом
чата; если ключа нет (например, новое устройство), такой черновик просто
пропускается — вместо него покажется локальная копия, если она есть.

## Когда черновик уходит на сервер

- пока идёт набор — с задержкой **1.5 с** после последнего изменения (API не
  дёргается на каждую букву);
- при уходе из чата и при сворачивании страницы (`visibilitychange` → hidden) —
  сразу, не дожидаясь задержки;
- при отправке сообщения или стирании текста — запрос на удаление.

Пустой текст означает «черновика нет»: сервер удаляет строку, а не хранит
пустую.

## Кто главнее при конфликте

Сервер считается источником правды: если он отдал черновик для чата, он
перекрывает локальную копию (её мог набрать кто угодно на другом устройстве).
Локальные черновики чатов, которых на сервере нет, не трогаем — запрос мог не
успеть уйти. Осознанное упрощение: текст, набранный в последние 1.5 с и
брошенный без сворачивания страницы, может не дойти до сервера — он останется
локально и уйдёт при следующем наборе в этот чат.

## API

- `GET /drafts/` — все мои черновики (`chat_id`, `text`, `updated_at`).
- `PUT /drafts/{chat_id}/` — сохранить (`{text}`, до 4000 символов; пустой текст
  удаляет черновик);
- `DELETE /drafts/{chat_id}/` — убрать черновик (204).

Черновик можно держать только в своём чате: в чужой — 404 (как у остальных
чатовых эндпоинтов, существование чата не подтверждаем). Лимит записи —
`DRAFT_WRITE_LIMIT_PER_MINUTE` (120), он выше «писательских» лимитов, потому что
сохранение идёт автоматически.
